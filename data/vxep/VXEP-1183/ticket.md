## Description

To eliminate the issue of a floating RJ45 connector inside the enclosure, we will build a custom 8P Pico to male RJ45 cable and mate it with a panel-mount female RJ45 jack, similar to the implementation used on the XComm.
This setup will secure the RJ45 interface at the panel, improve durability, and simplify external Ethernet connectivity.
