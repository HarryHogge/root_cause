## PURPOSE

The purpose of this report is to quantify the performance of the Proof of Concept (POC) 60cm C/S Band antennas.

## TESTS PERFORMED

Radiation pattern measurements and return loss measurements were conducted on the test items.

## DESCRIPTION OF TEST ITEM

The test items are POC 001 and POC 002 60cm C/S Band antennas.

## OBJECTIVES AND TEST CRITERIA

The objective is to quantify performance of the 60cm C/S Band antennas.

## TEST PROCEDURES

S-Parameter Measurements

Equipment List
Agilent Technologies E8363B Network Analyzer
Agilent 85056K 2.92/2.4 mm Calibration Kit

The network analyzer is set to measure S11. Equipment calibration is performed using the 85056K Calibration Kit and the Return Loss
is measured and recorded.

Radiation Pattern Measurements

Equipment List
Micro-Ant Spherical Test Facility
Keysight N5224A Programmable Network Analyzer
NSI-RF-5937 Amplifier
02-00635 Intelligent Measurement Controller
NSI2000 Antenna Measurement Software

The test facility is set for spherical nearfield measurements over the frequencies of interest. The spherical nearfield data is acquired, and the measurement software calculates and plots the far-field radiation patterns.
