Scope:
2024-06-21 (@Greg Fryer) Scope re-update. To support immediate need, product will be PWM driven by the existing control PCB (put in an enclosure). Removed need for a custom center wing, that will get moved to a future project if there is payload that needs it (or be incorporated natively into Havoc).

The purpose of this project is to create a finished, sellable product from the various prototype wing drop pylons that have been generated. Specifically, it shall:
- Be configured for the VXE30 Standard configuration (as produced currently, and for fielded vehicles)
- Support wing-drop of “whatever” via the provided/printable payload hooks.
- Specifically including the known FPV drones


It does not include:
- Management of munitions (fusing, tracking, safing, etc.)
- Configuration for special demo wings or Havoc wings, unless that happens to fit with no impact to the standard config
- More advanced targeting (which would require payload knowledge)

Other notes/constraints:
- Must include the usual support elements, specific ideas
- A full shipping case
- Documentation (operating and maintenance instructions)
- A quantity of spare drop hooks
- A separate catalog number for “a bunch of hooks and zip ties in a bag”
- Adapter cable described in payload feedback task
