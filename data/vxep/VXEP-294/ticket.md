## Description

Various customers require a transponder to operate in US airspace (and possibly other national airspaces). Currently we have an informal add-on, and LM has provided some functionality in the past (add on items).
Investigate various proposed transponders, provide appropriate interfaces, work with FLOPS to update manuals.
There is a need from US customers (SOCOM) for Mode 5 capabilities (which likely is ITAR controlled). There is also an international need, which would need a non-ITAR one so we can sell it easily.
