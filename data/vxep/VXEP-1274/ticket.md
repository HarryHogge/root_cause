## Description

This task tracks the creation, review, and release of the Software Configuration Matrix (SCM) for the LRR HIL (Stalker Block 35X) system. The SCM will define all required software components, their versions, branches, and configuration parameters to ensure consistent system setup across production and integration.
This matrix will serve as the single source of truth for software setup, helping align Engineering, Test, and Production teams during build, checkout, and delivery.
