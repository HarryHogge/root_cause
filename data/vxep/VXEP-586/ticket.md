## Description

Note this is a catch-all project for all remaining goops, after specific projects are done. This may need to be broken down into smaller batches depending on how many items are left after those projects finish.

Supply chain has generated this list (subject to review) of all the adhesives/sealants currently in use. This project is to identify two things, wherever possible:
- Identify an alternate material (e.g. instead of Loctite 242, we can also use “Superglue 7A3”)
- Identify alternate sources for each material.
- Bonus points for faster curing time.
