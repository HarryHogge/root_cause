## Description

SGCS Kits 102 and 103 are having issues completely updating to GCS Version 6.3.4. When kits are updated to 6.3.4, and aircraft firmware version is queried through the help-about dropdown, the software will suggest and older version of firmware for “updating”. Or, if the aircraft is on a previous version of firmware, there will be no update suggested, or it will be unavailable. On kit 102, there are elements of previous VXE GCS software that cannot be deleted through the ADD/DELETE programs screen. Kit 103 does not have these elements but has the same bugs in the updated 6.3.4 software update.
