## Description

Revision B was created for part number 965-1-01-1806 to solve an issue on the fuselage power harness assembly (107-102189).
Both 96X-3-09-0011 and 1803C03A (GCS assemblies) use part number 965-1-01-1806 as well. Neither of these assemblies can use revision B. As a result, these assemblies must continue using revision A of 965-1-01-1806.
This causes issues for our supply chain, inventory control, production, and quality since revision A is no longer a released part in the vault. We would like engineering support to create a new part number for 965-1-01-1806 Revision A and release it on the vault. We would then like to have the BOMs updated for both 96X-3-09-0011 and 965-1-01-1806 to reflect this new part number.
107-102189 should continue to use 965-1-01-1806 Revision B.
Please see Emalee or Trevor with any questions on this request.
