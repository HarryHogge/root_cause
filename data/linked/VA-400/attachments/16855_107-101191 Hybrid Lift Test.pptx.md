Before beginning any testing, you will want to make the battery as close to the finished product as possible which may include adding in the last bit of foam to the container if it is not already present.
Next you will want to plug the battery into the iCharger.
Set the charger to the monitor setting at 3.14V/Cell and start the monitor.
Go to the computer with the Logview app and open. Go to Device  Choose Device  Juns1 iCharger 3010B
Next, while under Device, select “Open Port/ Recording.”
You will need two computers, a hybrid lift battery charger, and the larger load BK Precision machine for this test.
One computer will be necessary to run the BK Precision program, and the other (Tornado) computer will be needed to run the Logview.
You may need to complete user setup for the Logview app in which case go through standard procedures, apart from manually changing preferred language to English as the default language will automatically be set to Dutch.

With Logview refreshed, go start the BK Test program then wait.
These tests last approximately 8 minutes, but you must be at the ready to emergency stop the test if a failure occurs. 
A single beep usually means the test is fully complete and is no cause for worry.
If there are many beeps, then it may indicate a failure in one of cells by dropping voltage too fast which will mean you need to shut off the test as soon as possible.
