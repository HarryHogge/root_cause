## Description

When updating missions (move, edit, recreate, etc) the mission being updated will have the correct MSL values. However, the GCS then automatically updates the other missions with MSL values based on the origin location instead of the waypoint location.
This can be recreated by moving the origin to a location that has a very different elevation than the mission locations. Then update a mission and refresh the mission table.
Refer to incident https://jenaero.atlassian.net/browse/VXEP-546 for more information.

## Comments (6)

### Eric Engstrom, 2024-11-18

Some reproduction steps. These assume the view is centered on the airstrip at Fort Hunter-Liggett (at approx. 10 SGE 0219454849). 
There are at least two distinct bugs misbehaviors here:
- The MSL in the Mission Table is being calculated incorrectly with respect to the origin point reference elevation.
- The simulator returns different incorrect results after the origin point has been moved. (This became an issue during investigation because the simulator is run as part of the launch wizard.) EDIT TO ADD: the simulator is probably returning incorrect results for any case where the elevation of the origin point and the actual reference elevation (i.e., where the vehicle is calibrated) differ by more than a few feet.

**Incorrect MSL in Mission Table View**

- Use the Place Origin tool to place the origin point on the runway.

[embedded: image-20241118-183837.png]
- Click the Quick Mission button.
- A mission is added around the origin point.
- Click the Table Edit button.
- The Mission Table View opens.
- In the Mission Table View, note the MSL of a waypoint (e.g., L).
- Use the Place Origin tool to move the origin point to the top of a nearby ridge.
- In the Mission Table View, click Reload.
- The MSL for every waypoint has changed.
- In the Mission Table View, note the MSL of the waypoint noted in step 4 (e.g., L).
- The difference in MSL is the difference in altitude between the runway and the top of the ridge.
- Use the Place Origin tool to move the origin point back to the runway.
- In the Mission Table View, click Reload.
- The MSL for every waypoint reverts to its original value.

**Incorrect results from the Simulation**

- Click Waypoint → Clear Mission to clear the previous mission, if needed.
- Use the Place Origin tool to place the origin point on the runway.
- Click the Quick Mission button.
- A mission is added around the origin point.
- Click the Run Simulation button.
- Simulation Results: Mission valid. Displayed vehicle tracks are all purple.
- Note: some relative MSL values will be “fixed up” in the mission’s waypoints. (These can be seen in the Mission Table View.) This is due to inconsistent relative altitude values in the waypoints, as generated by the Quick Mission tool. This appears to be a bug in the Quick Mission tool, rather than the simulator.
- Close the Simulation Results window.
- At this point, you can use the Sim Query tool to inspect the altitudes along the vehicle tracks. They should approximately match the altitudes described by the mission waypoints.
- Click the Clear Sim button to dismiss the tracks from the simulation.
- Use the Place Origin tool to move the origin point to the top of a nearby ridge.
- Click the Run Simulation button.
- The simulation results will show flight level errors. The vehicle tracks will show red segments.
- Close the Simulation Results window.
- Use the Sim Query tool to inspect the altitudes along the vehicle track.
- Altitudes are far off from those specified by the mission waypoints.
- Click the Clear Sim button to dismiss the tracks from the simulation.
- Use the Place Origin tool to move the origin point back to the runway.
- Click the Run Simulation button.
- Simulation Results: Mission valid. Displayed vehicle tracks are all purple.

### Eric Engstrom, 2024-12-02

The crux of the problem is that some code is incorrectly using the elevation of the origin point as the reference elevation. This results in incorrect “fixups” to waypoints when a mission is edited, or the origin point is changed. The origin point’s elevation and the reference elevation are different concepts. 
Additionally, when the reference elevation does change (e.g., when the aircraft is calibrated), the Altitude and GroundAltitude members of each waypoint in the mission need to be adjusted. 
The two behaviors noted in my Nov 18th comment both stem from these two issues.
